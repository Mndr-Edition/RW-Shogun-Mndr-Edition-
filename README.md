Интерактивная веб-панель управления и подробный журнал обновлений для глобальной модификации **SHOGUN: MNDR EDITION** (игра *Rusted Warfare*), переносящей действие в суровую эпоху Сэнгоку Дзидай.

Этот репозиторий содержит фронтенд-код стильного бортового журнала, предназначенного для удобной фильтрации патчноутов, быстрого скачивания `.rwmod` файлов и отслеживания технического прогресса разработки.

---

## 🛠️ Технический стек и особенности кода страницы

Сайт представляет собой оптимизированный Single Page Application (SPA), написанный на чистых веб-технологиях без тяжелых фреймворков:

* **Интеллектуальный «Умный Поиск» (JS):** Кастомная поисковая система с debounce-таймером (`150ms`) для снижения нагрузки. Ищет совпадения по тексту, тегам и датам, динамически подсвечивая результаты (`search-highlight`) и выводя количество найденных карточек.
* **Эффект «Печатающей машинки»:** При первой загрузке страницы заголовки и описания плавно печатаются в реальном времени через рекурсивные функции JS.
* **Продвинутый CSS3 & Анимации:**
  * Градиентные неоновые рамки меню на базе `@property --angle` и `conic-gradient`, вращающиеся на 360 градусов.
  * Плавное аппаратное смещение карточек при наведении (`transform: translateY(-2px)`) и кастомный скроллбар.
* **Адаптивный Mobile-First дизайн:** Полная перестройка макета в одну колонку на экранах смартфонов (до `768px`) с фиксом горизонтального скролла.
* **Пасхалки и секреты:** В коде скрыта секретная карточка разработчика (`hidden-manifest`), которая становится видимой только при вводе ключевых слов: `манифест`, `manifest` или `mndr`.

## 📌 Ключевые изменения в моде (Патчноут v5.0)

Интерфейс структурирует огромный объём технической работы над игровым процессом:

* **ARMY LOGIC 3.0 & Tactical Micro:** Полная деструкция старой логики ИИ. Юниты объединены в систему `JoinTheArmy` (копируют приказы лидера). Кайт стрелков и использование способностей переведены на вероятностную логику (шанс 70-85%), что снизило нагрузку на процессор в 2 раза и убрало эффект «роя роботов».
* **The Great Purge (Великая Зачистка):** Тотальное удаление ванильных ассетов и скрытых ID через `overrideAndReplace`. Мод стал полностью автономным.
* **Экономическая революция (`AI_AutoJobs`):** ИИ самостоятельно оценивает казну и перераспределяет рабочих по ролям (Рис/Золото/Дерево). Все циклические проверки переведены на `every8Frames`, что полностью убрало микро-фризы.
* **Hero Mechanics & Arts:** Внедрена система энергии для уникальных ультимейтов (у Лучника — «Шквал стрел», у Катаны — прыжок за спину «Counter-Step»).
* **Amphibian Lock:** Тяжёлые корабли (Heavy Bune) больше не могут ездить по суше как танки — срабатывает триггер принудительного отката в воду.
* **Акустический прорыв:** Обход лимитов движка через векторную инъекцию `movementEffect` — добавлено 8 вариаций звуков шагов в зависимости от типа войск.
